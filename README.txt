# AFRICA CALLING — Cloudflare Pages

This is a static website prepared for Cloudflare Pages.

## Deploy with Cloudflare Pages Direct Upload

Upload this folder as the deployment directory.

Build settings:
- Framework preset: None / No framework
- Build command: leave blank
- Build output directory: /
- Production branch: not required for Direct Upload

The important files are:
- index.html
- africa-calling-logo.png

No Node.js, npm, or build process is required.

## Before launch
1. Replace the video placeholders in `index.html` with the real sample videos.
2. Replace the WhatsApp placeholder link with the real business WhatsApp link.
3. Connect the DPO checkout when approved.
4. Add Privacy Policy, Terms & Conditions, and Refund Policy pages/links.
